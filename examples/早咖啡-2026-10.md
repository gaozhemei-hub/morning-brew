# 一、商业与战略层（看钱和壁垒）

> **本期投资人视角的一句话**：这一周最值钱的信号不是模型发布，而是**"AI 的钱开始从模型层流向电力和土地"**——Anthropic 在为一个 245MW 的数据中心签租赁、机器人赛道一年吸金 480 亿美元、Yandex 三座数据中心被无人机打瘫。**算力的物理约束正在变成投资主线。**

### 1. Anthropic 数据中心租赁的账被算出来了：一个 245MW 站点年收入约 13 亿美元 `[必须知道]`
- **核心观点**：
  - The Information 拆解了 Anthropic 的数据中心**租赁经济学**：分析师测算单个 **245MW** 站点年收入可达约 **13 亿美元**。
  - 关键含义：**"租算力"正在变成一个可被金融建模的资产类别**——有稳定现金流、可测算的单位经济（MW → 收入）。
  - 这解释了为什么这一轮 AI 的钱大量流向**电力、土地、机房**而不是应用层：**资产端比应用端更容易被定价**。
- **为什么现在**：当模型公司的成本结构可以被第三方拆成"每 MW 对应多少收入"时，AI 就从"讲故事"进入了**可做 DCF 的阶段**——这是资本市场对赛道真正下注的标志。

### 11. ★ OpenAI 一次放出 722 篇数学论文手稿，全部来自一个未发布的内部模型 `[必须知道]`
- **核心观点**：
  - 手稿归为 **372 个结果家族**，横跨 **17 个数学领域**，部分**配有 Lean 形式化证明**；出自一个**尚未发布、未公开命名**的内部前沿模型，据称**强于 GPT-6 Astra**。
  - 数学界的反应是"**AI 产出新数学的速度，开始超过数学界理解数学的速度**"——**科研项目被抢跑、同行评议体系承压**。
  - 陶哲轩在同一天公开演讲《**Math 2.0**》，主题是"**证明稀缺的时代正在终结**"（该演讲原定 5 月，因近期事件推迟到 10 月）。
- **为什么现在**：这是**"AI 从工具变成研究者"的第一个可验证事件**，而它带出的不是能力问题而是**制度问题**（谁来评审、知识产权归谁、学术信用怎么算）。面试里谈"AI 产品的边界"，这是目前最硬的例子。
- **衡量方式**：这类能力的评测不是准确率，而是**可验证性**——**能不能被 Lean 形式化检验**。这也是"评测怎么做"最前沿的答案。

### 13. ★ 论文里的信号：评测/审计正在成为独立赛道（今天有 4 篇同题材） `[值得知道]`
- **核心观点**：
  - **AgentForesight**（NeurIPS 2026）：用**一个 7B 模型在任务运行中持续审计**，**在任务失败前**识别关键错误——"从事后归因到在线审计"。动机很实在：**多智能体的失误未必当场报错，一个 Agent 给出错误前提，其他 Agent 会继续认真执行。**
  - **Opera**：给**长时程编码 Agent** 的"**言语批评家**"框架——指出反馈在误导时**不仅无效甚至有害**。

- **为什么现在**：这四篇指向同一件事——**"AI 的错误"已经从"答错题"变成"悄悄跑偏"**，所以**在线审计/过程评测**会成为独立产品层。**这正好是你面试岗位的日常。**
- **衡量方式**：**在线审计看"失败前召回率"与误报率**；长时程任务看**中途纠偏后的最终成功率**，而不是只看终局。

  - **LegalOn**：**日均 Codex 成本降 65%**，做法是**把 Astra / Sol / Luna 按任务匹配**并做预算分层。
  - **Oracle**：把专家知识变成"**快速可重复工作流**"（招聘/工程/运营）。
  - 含义：**企业 AI 的价值主张已经从"更聪明"变成"单位任务成本"**；而**降本靠的是"模型路由"这种产品能力，不是模型本身**。
- **为什么现在**：这是"**AI 产品经理该做什么**"的最直接答案——**把对的模型派给对的任务**，是纯产品活。
- **衡量方式**：**单位任务成本（cost per task）**、**成本/质量曲线**，而不是单点 benchmark。
- **来源**：OpenAI Blog（2026-10-08/09）<https://openai.com/index/asana-browser-agent>｜<https://openai.com/index/legalon-halves-codex-costs>｜<https://openai.com/index/oracle>

### 16. ★ Microsoft-Decision-1：一个**新模型品类**被正式命名 `[必须知道]`
- **核心观点**：
  - 微软发布 **Microsoft-Decision-1**，一个**快速的决策评分模型**，基于 **Qwen3.5-9B** 训练；微软同时说**将很快 rebase 到 MAI、OpenAI 等模型**上。
  - 决策模型与 LLM 的区别是本质性的：**它不生成文本，只给"该采取哪个行动"打分**——所以它可以很小、很快，并且**底座可以随时换掉**。
  - 微软的动作顺序值得抄下来做笔记：**先在开源的 9B 上把品类验证出来，再宣布换成自家（MAI）与 OpenAI 的底座**——用别人的模型证明品类，再把品类收回自己的栈。
- **为什么现在**：这是 2026 下半年第一个"**新模型品类**"信号（HF Blog 同期还有 LiquidAI 面向边缘的决策模型 open-d1）。对 agent 架构的含义很直接：**"选哪条路"会从 LLM 里拆出来成为独立一层**——规划/选择交给决策模型，执行与表达交给 LLM，两层独立评测、独立换底座。**你要面的 AI 产品岗，今年的系统设计题大概率长这样。**
- **衡量方式**：决策模型不看文本质量，看 **regret（与最优决策的差距）+ 决策延迟**；这类评测集正在成形，还没有公认基准——**谁先定口径谁就有话语权**。
- **名词**：[[技术名词库#决策模型|决策模型↗]]
- **来源**：Techmeme 引 Command Line（2026-10-11）<https://www.techmeme.com/261011/p2#a261011p2>

### 17. DeepSeek 的「神鬼二象性」：多敲几个空格，答案从天才变智障 `[值得知道]`
- **核心观点**：
  - 字节论文《Periodic Weak Spots: Phase Sensitivity from Chunked KV-Cache Compression》（arXiv 2609.36322）点名 **DeepSeek V4 系列**：**分块 KV Cache 压缩**带来"**位置决定命运**"——核心词不巧落在切块交界的盲区，模型只能胡言乱语。
  - 场景化的后果：让模型审几十页合同，**关键条款正好卡在"信息盲区"时结论可能完全错**，而表面上一切正常。
  - 含义：**长上下文压缩（省钱的主路线）有系统性失败模式**，不是偶发 bug。
- **为什么现在**：所有"能读长文档"的卖点都要先过这一问。对企业采购和你做评测集都是直接的尽调项——**这也是最容易被写进面试加分项的细节**。
- **衡量方式**：**同一问题的扰动一致性（perturbation consistency）**——换措辞、加空格、换位置，答案是否稳定；长文本场景必须加进评测集。
- **名词**：[[技术名词库#分块 KV Cache 压缩|分块 KV Cache 压缩↗]]｜[[技术名词库#KV Cache|KV Cache↗]]
- **来源**：雷锋网（2026-10-10）<https://www.leiphone.com/category/yanxishe/zm33Zeu88CNbEPMx.html>

### 18. LIBERO-MAX：用 22.4 万次仿真检验机器人的「动态可靠性」 `[值得知道]`
- **核心观点**：
  - 场景：机器人伸手去拿桌上的杯子，**人顺手把杯子挪开几厘米**——机器人看到的是旧位置、生成的动作指向旧位置，手可能抓空。
  - LIBERO-MAX 用 **22.4 万次仿真轨迹**专门检验这种**动态可靠性**（而非静态抓取成功率）。
  - 含义：**具身智能的评测标准正在从"能不能做到"变成"被打断后还能不能做到"**——这更接近真实商用场景。
- **为什么现在**：与第一层（年内 480 亿美元融资、2.7 万台 robovan）是同一件事的两端：**资本在按"五年落地"定价，评测才刚补上"动态"这块短板**——缺口就是岗位。
- **衡量方式**：**人为干扰下的任务成功率**（物体被移动/人经过时的成功率），而不是无干扰 benchmark。
- **来源**：机器之心（2026-10）<https://www.jiqizhixin.com/articles/374601ea-9a6b-4bf4-8895-c09fd4a013ce>

### 19. Claude Opus 5.5 把数百款老游戏反编译进浏览器：agent 吃下"存量资产迁移" `[值得知道]`
- **核心观点**：
  - Kotaku 报道：数百款老游戏近几周被**反编译并移植到浏览器运行**，主要由 **Claude Opus 5.5** 驱动；GTA: Vice City、Halo: CE、CoD: Black Ops、Skate 3 等运行良好。
  - 含义：**"长链条 + 可验证 + 可批量"的工作**（反编译→修依赖→跑起来→确认能玩）是 coding agent 最先吃下的市场——因为有客观的通过判据。
  - 这条也说明 **agent 能力外溢到了没人预先规划的场景**——存量数字资产的迁移维护会变成一个外包型行业。
- **为什么现在**：判断 coding agent 的真实能力边界，看它能不能完成**有硬性验收标准的长链条任务**，比看 benchmark 靠谱。
- **衡量方式**：**移植后可运行比例 / 可玩性**（可验证性），而不是生成代码的行数或速度。
- **来源**：Techmeme 引 Kotaku（2026-10-10）<https://www.techmeme.com/261010/p17#a261010p17>

### 20. Product Hunt 今日新上线：「多 agent 调度」的界面层开始出现 `[值得知道]`
